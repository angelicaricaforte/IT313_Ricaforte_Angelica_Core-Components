Student Directory Viewer

Problem

This project is a student directory application
that allows users to browse and search students
who need academic advising.

Components

StudentCard

Displays the student's photo, name, year level,
and Flag for Advising button.

StudentDirectory

Manages the student list, search functionality,
and flagged student states.

React Native Components

- View
- Text
- Image
- ScrollView
- TextInput
- Pressable

How to Run

1. Install Node.js.
2. Install Expo.
3. Run npx expo start.
4. Open the application using Expo Go
